sarh/app.js

Sarh services marketplace

An Arabic RTL marketplace connecting business owners with vetted providers of web, branding, marketing, content and video, with clear prices. A complete product, not a mockup.

  • Four interfaces in one hash-routed app: customer, provider dashboard, admin console and notification bell, split across about 25 single-purpose ES modules. No framework.

  • Resilient by design: service worker, offline and outage pages, and a fallback to sample data when the API is down.

~/processHow I build

build.pipeline
  1. 01

    Idea

    Start from a real gap: a market, a messy workflow, a thing I wish already existed.

    out: a problem worth solving
  2. 02

    Plan

    Sketch the screens and the data shape before any code, so the UI and the API agree from the start.

    out: screens + data model
  3. 03

    Build

    Front end first, framework-free where it makes sense, components kept small and single-purpose.

    out: working vertical slice
  4. 04

    Secure

    Sessions, input and errors get the same attention as layout: CSP, CSRF, escaping, rate limits.

    out: hardened by default
  5. 05

    Test

    Click through it like a user who never reads instructions, on a slow connection, in Arabic and English.

    out: bugs found before users do
  6. 06

    Ship & improve

    Deploy, watch how it behaves for real, and fold what I learn back into the next build.

    out: live, then better
